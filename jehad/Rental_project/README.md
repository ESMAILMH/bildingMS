# نظام إدارة العقارات والإيجارات وتتبع دفعات المستأجرين

**كلية التقنيات الهندسية – يفرن | قسم تقنية المعلومات**
تطبيق ويندوز (C# / .NET 8 Windows Forms) مع قاعدة بيانات **SQL Server** عبر **ADO.NET**،
مبني على مقترح المشروع وقاعدة البيانات `RentalDB` (8 جداول، عرضان، 6 إجراءات مخزنة).

## التشغيل

1. افتح الملف `Database/01_RentalDB.sql` في SSMS من **File ← Open ← File** واضغط Execute.
   ينشئ قاعدة `RentalDB` بالجداول والعروض والإجراءات المخزنة.
   > إذا ظهرت أخطاء مثل `There is already an object named ...` فهذا يعني أن الجداول أُنشئت سابقاً في قاعدة master:
   > شغّل `Database/00_Cleanup.sql` مرة واحدة، ثم أعد تشغيل `01_RentalDB.sql`.
2. *(اختياري)* شغّل `Database/02_SampleData.sql` لإضافة بيانات تجريبية
   (4 عقارات، 14 وحدة، 8 مستأجرين، 7 عقود، 21 دفعة؛ التواريخ نسبةً ليوم التشغيل فتظهر التنبيهات دائماً) مع حسابات دخول:
   `admin / Admin@123` (مدير) — `employee / Emp@123` (موظف).
3. افتح `RentalManagement.sln` في Visual Studio 2022 واضغط **F5**.
4. **أول تشغيل بدون بيانات تجريبية:** يطلب التطبيق إنشاء حساب **المدير** (كلمة المرور تُشفَّر في C# ثم تُحفظ).
5. إذا كان اسم الخادم غير `.\SQLEXPRESS` عدّله من **إعدادات الاتصال** في شاشة الدخول، أو من `appsettings.json`.

المتطلبات: Windows 10 أو أحدث، Visual Studio 2022، .NET 8، SQL Server 2016 أو أحدث (Express يكفي).
الحزم: `Microsoft.Data.SqlClient` (ADO.NET) و `ClosedXML` (Excel) — تُحمَّل تلقائياً من NuGet.

## قواعد العمل المطبّقة داخل قاعدة البيانات

- **عقد نشط واحد لكل وحدة:** فهرس فريد مرشّح `UX_Contract_OneActivePerUnit`.
- **كل عملية مركّبة = معاملة واحدة** (`SET XACT_ABORT ON` + قفل `UPDLOCK`): إبرام العقد، الدفع، الإلغاء، الإنهاء، الفسخ، التجديد.
- **المدفوع لا يتجاوز قيمة القسط:** `CK_Installment_Paid`.
- **الإيصال لا يُحذف:** يُلغى (للمدير) ويعود مبلغه إلى رصيد القسط.
- رقم العقد `C-00001` ورقم الإيصال `R-000001` وحالة القسط **أعمدة محسوبة**.

## الاختبار

اختُبرت السكربتات والإجراءات المخزنة وطبقتا DAL/BLL على SQL Server 2022 بالبيانات التجريبية:
حالات الخطأ (50002، 50006، 50008، 50009، 50012، القيود الفريدة)، تطابق جدول الأقساط بين C# و SQL لكل العقود،
بناء التقارير الثلاثة عشر، ودورة كاملة (عقار ← وحدة ← مستأجر ← عقد ← دفعة ← إلغاء ← تجديد ← فسخ).
الشاشات نفسها تحتاج تشغيلاً على Windows للتأكد منها.

## الخط: Cairo

كل البرنامج (الشاشات والتقارير المطبوعة) يستخدم خط **Cairo** (ملفاته في `RentalManagement/Fonts`، رخصة SIL Open Font License).
عند أول تشغيل يثبّته البرنامج تلقائياً للمستخدم الحالي ثم يطلب إعادة فتحه مرة واحدة.
ليظهر داخل مصمم Visual Studio: ثبّت `Cairo-Regular.ttf` و `Cairo-Bold.ttf` يدوياً ثم أعد تشغيل Visual Studio.
