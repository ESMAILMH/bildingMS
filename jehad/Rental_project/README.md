# نظام إدارة العقارات والإيجارات وتتبع دفعات المستأجرين

**كلية التقنيات الهندسية – يفرن | قسم تقنية المعلومات**
تطبيق ويندوز (C# / .NET 8 Windows Forms) مع قاعدة بيانات **SQL Server** عبر **ADO.NET**،
مبني على مقترح المشروع وقاعدة البيانات `RentalDB` (8 جداول، 3 عروض، 6 إجراءات مخزنة).

## التشغيل

1. افتح الملف `Database/RentalDB_Full.sql` في SSMS من **File ← Open ← File** واضغط Execute.
   ينشئ قاعدة `RentalDB` بالجداول والعروض والإجراءات المخزنة **مع البيانات التجريبية**
   (يساوي تشغيل `01_RentalDB.sql` ثم `02_SampleData.sql`). لقاعدة فارغة شغّل `01_RentalDB.sql` وحده.
   > إذا ظهرت أخطاء مثل `There is already an object named ...` فهذا يعني أن الجداول أُنشئت سابقاً في قاعدة master:
   > شغّل `Database/00_Cleanup.sql` مرة واحدة، ثم أعد التشغيل.
2. البيانات التجريبية (أسماء ليبية، والتواريخ نسبةً ليوم التشغيل فتظهر التنبيهات دائماً) تغطي كل الحالات:
   5 عقارات (أحدها معطّل)، 15 وحدة (شاغرة / مؤجرة / صيانة)، 9 مستأجرين (أحدهم معطّل)،
   9 عقود (نشطة، منتهٍ، مفسوخ، وعقد انتهت مدته ولم يُغلق)، أقساط مسددة وجزئية ومتأخرة، و27 إيصالاً أحدها ملغى.

   | الحساب | كلمة المرور | الدور |
   |---|---|---|
   | `admin` | `Admin@123` | مدير |
   | `employee` | `Emp@123` | موظف |
   | `staff` | `Staff@123` | موظف |

3. افتح `RentalManagement.sln` في Visual Studio 2022 واضغط **F5**.
4. **أول تشغيل بدون بيانات تجريبية:** يطلب التطبيق إنشاء حساب **المدير** (كلمة المرور تُشفَّر في C# ثم تُحفظ).
5. إذا كان اسم الخادم غير `.\SQLEXPRESS` عدّله من **إعدادات الاتصال** في شاشة الدخول، أو من `appsettings.json`.

المتطلبات: Windows 10 أو أحدث، Visual Studio 2022، .NET 8، SQL Server 2016 أو أحدث (Express يكفي).
الحزم: `Microsoft.Data.SqlClient` (ADO.NET) و `ClosedXML` (Excel) — تُحمَّل تلقائياً من NuGet.

## قواعد العمل المطبّقة داخل قاعدة البيانات

- **عقد نشط واحد لكل وحدة:** فهرس فريد مرشّح `UX_Contract_OneActivePerUnit`.
- **كل عملية مركّبة = معاملة واحدة** (`SET XACT_ABORT ON` + قفل `UPDLOCK`): إبرام العقد، الدفع، الإلغاء، الإنهاء، الفسخ، التجديد.
- **القيم المحسوبة لا تُخزَّن:** المدفوع والمتبقي وحالة القسط في العرض `vw_InstallmentBalance`، وأرصدة العقد في `vw_ContractSummary`.
- **المدفوع لا يتجاوز قيمة القسط:** يُفحص في `sp_RecordPayment`.
- **الإيصال لا يُحذف:** يُلغى (للمدير) فلا يُحسب في المدفوع.
- رقم العقد `C-00001` ورقم الإيصال `R-000001` وحالة القسط **أعمدة محسوبة**.

## النشر على جهاز آخر (Self-contained)

نسخة لا تحتاج تثبيت .NET على الجهاز الآخر:

```bash
dotnet publish RentalManagement/RentalManagement.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

(أو من Visual Studio: زر الفأرة الأيمن على المشروع ← Publish ← Folder ← Deployment mode: Self-contained، Target runtime: win-x64.)

انسخ مجلد `publish` كاملاً (فيه `RentalManagement.exe` و `appsettings.json` و `app.ico` ومجلد `Fonts`) إلى الجهاز الآخر، ثم:
1. ثبّت SQL Server Express على ذلك الجهاز (أو على خادم في الشبكة).
2. شغّل `Database/RentalDB_Full.sql` (أو `01_RentalDB.sql` لقاعدة فارغة).
3. شغّل `RentalManagement.exe`، وعدّل اسم الخادم من «إعدادات الاتصال» في شاشة الدخول إن لزم.
